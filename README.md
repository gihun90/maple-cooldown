# 메이플 스킬바 미러

메이플스토리 스킬 아이콘 몇 개를 골라서, 항상 위에 떠 있는 작은 창에 확대해서 보여주는 프로그램입니다.
다른 모니터에서 유튜브를 보면서 재획할 때 쿨타임을 놓치지 않으려고 만들었습니다.

- 화면에 보이는 것을 **캡처만** 합니다. 게임 메모리나 파일은 건드리지 않습니다 (OBS로 화면 녹화하는 것과 같은 원리).
- 메이플은 **창모드**여야 합니다. 전체화면(exclusive)이면 캡처가 되지 않습니다.
- 윈도우 전용.

## 그냥 쓰기

1. 오른쪽 **Releases**에서 `메이플스킬바미러.exe`를 받습니다.
2. 아무 폴더에 넣고 더블클릭합니다. (설정은 exe 옆에 `config.json`으로 저장됩니다.)
3. 처음 뜨는 윈도우 보안 경고는 서명 안 된 개인 제작 프로그램이라 뜨는 것입니다. **추가 정보 → 실행**.

## 사용법

설정창이 하나, 미러 창이 하나 뜹니다.

**칸 놓기 (처음 한 번)**
1. **칸 추가** → 메이플 창 안에 초록 테두리 네모가 생깁니다.
2. 테두리를 마우스로 끌어서 스킬 아이콘 위에 딱 맞춰 올립니다. 네모 안쪽은 투명하고 클릭이 게임으로 통과됩니다.
3. **칸 추가**를 다시 누르면 바로 옆 아이콘 자리에 생깁니다. 필요한 만큼 반복.
4. 크기가 안 맞으면 **칸 크기** 숫자를 바꾸거나 테두리 위에서 휠을 돌립니다. 모든 칸이 한 번에 바뀝니다. (기본 32 = 메이플 기본 아이콘 크기)
5. 잘못 만든 칸은 테두리 **오른쪽 클릭**으로 삭제.
6. **편집 끝** → 테두리가 사라지고 미러에만 남습니다.

**미러 창**
- 마우스로 끌어서 옮기기. **미러를 다른 모니터로** 버튼으로 모니터를 건너뛸 수 있습니다.
- **확대 배율 / 투명도 / 갱신 속도** 슬라이더.
- **한 줄에 N칸**: 미러에서 줄바꿈. 0이면 한 줄.

**메이플 창을 옮겨도** 칸이 따라갑니다. 단, 메이플 창 크기나 UI 배율을 바꾸면 칸을 다시 놓아야 합니다.

## 직접 빌드하기

Python 3.12 이상.

```
build.bat
```

처음 실행하면 `.venv`를 만들고 라이브러리를 설치한 뒤 exe를 만듭니다.
exe 없이 바로 실행하려면 `run.bat`.
