# 메이플 스킬바 미러

메이플스토리 스킬 아이콘 몇 개와 내 캐릭터를, 항상 위에 떠 있는 작은 창에 확대해서 보여주는 프로그램입니다.
다른 모니터에서 유튜브를 보면서 재획할 때 쿨타임과 캐릭터 상태를 놓치지 않으려고 만들었습니다.

- 화면에 보이는 것을 **캡처만** 합니다. 게임 메모리나 파일은 건드리지 않습니다 (OBS로 화면 녹화하는 것과 같은 원리).
- 메이플은 **창모드**여야 합니다. 전체화면(exclusive)이면 캡처가 되지 않습니다.
- 윈도우 전용. (맥 버전은 준비 중)

## 그냥 쓰기

1. 오른쪽 **Releases**에서 `MapleSkillMirror-vX.X-windows.zip`을 받습니다.
2. 압축을 풀고, 폴더 안의 **`MapleSkillMirror.exe`**를 더블클릭합니다. 폴더 안 `_internal`은 지우지 마세요 (프로그램 부품입니다). 설정은 같은 폴더에 `config.json`, `nametag.png`로 저장됩니다.
3. 처음 뜨는 윈도우 보안 경고는 서명 안 된 개인 제작 프로그램이라 뜨는 것입니다. **추가 정보 → 실행**.

> exe 한 개로 묶은 버전은 윈도우 디펜더가 `Wacatac.B!ml`(머신러닝 추측)로 오탐해서 폴더 형태로 배포합니다. 코드는 이 저장소에 전부 공개돼 있고, 못 믿겠으면 아래 "직접 빌드하기"로 본인 PC에서 만들면 됩니다.

## 처음 설정 (마법사가 안내합니다)

처음 켜면 **처음 설정** 창이 뜹니다. 세 단계입니다.

1. **스킬 칸** — 초록 네모를 보고 싶은 스킬 아이콘 위에 하나씩 올립니다. `칸 추가`로 늘리고, 테두리를 끌어 옮기고, 오른쪽 클릭으로 삭제. 아이콘보다 크거나 작으면 `칸 크기` 숫자로 맞춥니다 (기본 32 = 메이플 기본 아이콘 크기).
2. **내 캐릭터 이름표** — 분홍 네모를 캐릭터 발밑 이름표에 딱 맞추고, 캐릭터가 가만히 서 있을 때 `이름표 저장`. 이걸 표식으로 삼아 캐릭터를 찾아서 별도 창에 보여줍니다. 필요 없으면 `건너뛰기`.
3. **멈춤 감시** — 주황 네모를 화면 맨 아래 경험치 숫자 위에 올립니다. 그 숫자가 몇 초 동안 안 바뀌면(사냥이 멈추면) 미러 창 테두리가 빨갛게 깜빡입니다. 필요 없으면 `건너뛰기`.

다 끝나면 네모들이 사라지고 미러 창만 남습니다. 다시 하려면 설정창의 `처음부터 설정`, 위치만 고치려면 `칸 편집`.

## 평소 쓰기

- **스킬 창**과 **캐릭터 창**은 각각 마우스로 끌어서 옮길 수 있습니다.
- 설정창: `스킬 배율` / `캐릭터 배율` 슬라이더, `캐릭터 표시` `동그랗게` `멈추면 빨간 테두리` 체크.
- `고급 설정 ▸`을 누르면 칸 크기, 이름표·감시 칸 크기, 멈춤 판단 시간·민감도, 투명도, 갱신 속도, `미러를 다른 모니터로` 등이 나옵니다.
- **메이플 창을 옮겨도** 칸이 따라갑니다. 단, 메이플 창 크기나 UI 배율을 바꾸면 칸을 다시 놓아야 합니다.

## 안 될 때

- 창이 비어 있거나 바로 꺼지면 exe **같은 폴더에 `log.txt`**가 생깁니다. 그 파일을 보내주세요.
- 오류 창이 다른 창 뒤에 숨어 있을 수 있습니다. 작업표시줄을 확인해 보세요.
- 이름표 인식이 안 되면(`이름표: 못 찾음`) 캐릭터가 서 있을 때 이름표를 다시 저장해 보세요. 이펙트가 이름표를 덮는 순간에는 잠깐 놓칠 수 있고, 그동안은 마지막 자리를 보여줍니다.
- 디펜더가 "바이러스가 있어 작업이 완료되지 않았습니다"라고 하면: 윈도우 보안 → 바이러스 및 위협 방지 → 보호 기록에서 해당 항목을 **허용**하거나, 아래처럼 직접 빌드하면 됩니다. (PyInstaller로 만든 파이썬 프로그램은 오탐이 잦습니다)

## 직접 빌드하기

Python 3.12 이상.

```
build.bat
```

처음 실행하면 `.venv`를 만들고 라이브러리를 설치한 뒤 `MapleSkillMirror\` 폴더에 exe를 만듭니다.
exe 없이 바로 실행하려면 `run.bat`.
